## 📌 About the Project

**Healthcare Data Analysis** is a practical data wrangling project developed using
Python and Pandas.

The project demonstrates the complete process of working with a raw dataset,
understanding its structure, identifying data quality issues, cleaning and
transforming the data, and preparing a final dataset for further analysis.

This project was completed as part of a **Data Analytics learning project
(Week 3 – Data Wrangling)**.

---

## 🎯 Project Objectives

The main objectives of this project are:

- 🔍 Explore and understand the dataset
- 🧹 Clean and preprocess raw data
- 🔎 Identify missing values and duplicate records
- 🔄 Perform data transformation and wrangling
- 📊 Understand data types and dataset structure
- 💾 Create a cleaned and analysis-ready dataset
- 📝 Document the complete data preparation process
